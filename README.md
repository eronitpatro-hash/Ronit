# Ronit Patro — Finance Portfolio

Vercel-ready Next.js portfolio for a Finance & Accounting professional.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Deploy to Vercel
1. Upload this folder to a GitHub repository.
2. Import the repository into Vercel.
3. Vercel detects Next.js automatically.
4. Deploy.

## Before publishing
Replace the placeholder email and LinkedIn URL in `app/page.js` and optionally add a professional photo/resume.
